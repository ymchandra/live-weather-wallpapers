# Live Weather Wallpapers (Mobile)

Natural mobile wallpapers for weather conditions:

- hot
- cold
- rain
- wind
- calm

## Wallpaper files

Prebuilt phone wallpapers are in:

- `wallpapers/mobile/hot.png`
- `wallpapers/mobile/cold.png`
- `wallpapers/mobile/rain.png`
- `wallpapers/mobile/wind.png`
- `wallpapers/mobile/calm.png`

Resolution: **1290 x 2796** (vertical smartphone format).

## iPhone Shortcut

Use:

- `ios-shortcut/Live-Weather-Wallpaper-Shortcut.md`

It explains how to automatically set the matching wallpaper on iPhone based on current weather.
